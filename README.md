## 🌐 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/areeslindley/alun-website.git
   cd alun-website
   ```

2. **Open in browser**:
   ```bash
   # Simple local server (Python 3)
   python -m http.server 8000
   
   # Or using Node.js
   npx serve .
   
   # Then visit http://localhost:8000
   ```

3. **Development features**:
   - Live reload with any local server
   - Theme persistence across sessions
   - Responsive design testing tools
   - Performance monitoring in console
